Forthcoming
-----------

Changes since the first unofficial project version, ``v0.1.0``.

* Replace the follower-only launch with a shared SO-101 launch for 5-DOF and
  6-DOF leader and follower arms.
* Add namespaced leader–follower bringup and a separate launch entry point for
  teleoperation.
* Allow a custom robot description for workcell integration.
* Add control mode switching and manipulator and gripper trajectory
  controllers for planning integration.
