Forthcoming
-----------

Changes since the first unofficial project version, ``v0.1.0``.

* Replace the follower-only description with modular 5-DOF and 6-DOF arm
  descriptions and a reusable follower gripper.
* Add Onshape URDF and mesh exports for both arms and the gripper.
* Add DOF and role selection to the display launch and update the role-specific
  RViz presets.
* Add 6-DOF hardware control, provide calibration examples for both roles and
  DOF variants, and use the unified HiWonder hardware plugin.
* Correct the fourth joint's limits in the 6-DOF robot description.
